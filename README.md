## About me

I'm a software engineer with **6 years of C# / .NET** under my belt, based in northern Germany. Most of my work is backend and platform engineering for regulated industries (healthcare, finance): modernizing grown codebases, hardening authentication and identity, and running things on Azure with infrastructure as code.

I started as an apprentice, led a small dev team before I was 25, and now work as a consultant and trainer. I like clean APIs, boring architecture, good tests, and deleting code.

- 🔧 **Day job:** Backend & full-stack engineering at IT Titans GmbH
- 🔐 **Focus:** ASP.NET Core Identity, OIDC/OAuth, Keycloak, audit trails, ISO 27001 / GDPR traceability
- ☁️ **Cloud:** Azure (Container Apps, Managed Identity, Key Vault, Bicep), AWS (CDK, Fargate, Lambda)
- 🤖 **Also:** integrating LLM features into .NET products in a privacy-conscious way, and teaching teams how to work with coding agents without losing engineering discipline
- 🎓 **Certified trainer (AEVO)**, mentoring apprentices and junior developers

## How I work

- **Spec first.** Requirements, ADRs and tickets are written before code, sliced small enough to review in one sitting.
- **Tests that pay rent.** Unit tests for business logic, Testcontainers for integration, Playwright for the paths users actually take.
- **Security is a feature.** Threat-model the auth flow, rotate the keys, log the audit trail, redact PII before it leaves the boundary.
- **Agents as colleagues, not oracles.** I use coding agents in parallel git worktrees with a second model reviewing every change before merge. The engineering standards don't change, only the throughput.
